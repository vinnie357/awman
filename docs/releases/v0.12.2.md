# Release v0.12.2

Release of the `vinnie357/awman` fork.

The `v0.12.1` tag exists but never published a GitHub Release: its Windows
build leg failed and blocked the release job. `v0.12.2` carries the `v0.12.1`
fixes plus the release workflow change below.

## Fixes

- The codex agent image keeps the Codex package layout, so the app-server
  daemon starts again (from `v0.12.1`; see `docs/releases/v0.12.1.md`).

## Release workflow

- The `x86_64-pc-windows-msvc` target is dropped from release builds. It has
  failed to compile since `v0.11.3`. Restoring it is tracked in
  https://github.com/vinnie357/awman/issues/26. Releases ship Linux (amd64,
  arm64) and macOS (amd64, arm64) binaries.
