# Downstream candidate v0.12.1

This is a candidate release of the `vinnie357/awman` fork, based on upstream
AWMan `v0.12.0` at commit `c730732b`. It is not an upstream AWMan release and
has not been published or tagged yet.

The candidate adds the opt-in startup gate needed by an external orchestrator
to prepare a group of agent containers before releasing any agent. For gated
launches, AWMan validates the declared guest bindings and content manifests in
the running container, records nonce-bound readiness, and waits for the
matching release before executing the original agent command. Ungated launches
retain their existing behavior.

Docker and Apple Containers share the gated wrapper. Frontends and runtimes
that cannot preserve the same checks reject the option instead of silently
downgrading it. The control protocol keeps host and guest ownership checks
separate so UID/GID remapping on Apple Container mounts does not weaken either
boundary.

Before this candidate can become a release, the fork still requires its full
local, runtime, remote, and independent review gates. A future tag and release
assets must be built from the exact reviewed commit. Upstream `v0.12.0` does
not provide the startup-gate extension.
