# AWMan v0.11.3 - vinnie357 fork

This release follows the `vinnie357/awman` fork's 0.11.x version line and
incorporates work based on upstream AWMan 0.12.0. The binary identifies this
fork release as `awman 0.11.3`.

- Adds opt-in startup-gate controls for external orchestrators and native print
  and session-resume command surfaces.
- Includes captured project-input proof, isolated native SDK settings and
  authentication state, and conservative launch retention and recovery.
- Preserves separate ownership of project inputs, writable SDK state,
  child-process retirement, and uncertain publication or cleanup.
- Keeps non-interactive command stdio separate from interactive PTY handling.
- Allows cleanup deadlines to expire while resource destruction is still pending.

External startup control, including split-control orchestrated Apple launch,
is enabled as an experimental opt-in path. This release does not certify every
provider/runtime combination. The separate native Codex auth and main-execution
paths remain disabled in production pending qualification. Existing launch,
receipt, ownership and permission checks remain enforced.
